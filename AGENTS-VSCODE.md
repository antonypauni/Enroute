# Agents En Route dans VS Code

Ouvrir le dossier racine EnRoute dans VS Code. Ouvrir la vue de conversation, connecter GitHub Copilot si VS Code le demande, puis choisir un agent dans la liste.

- EnRoute Mobile traite Expo, Android et iPhone.
- EnRoute Serveur traite les API, les comptes et les courses.
- EnRoute Design traite l’interface web et mobile.
- EnRoute Qualite vérifie les parcours et les régressions.

Commencer avec EnRoute Mobile et cette demande : « Corrige la détection de @expo/ngrok installé mais introuvable, puis vérifie le démarrage Expo Go sur Windows. »

Pour un contrôle global : « Utilise EnRoute Qualite pour vérifier les parcours client, chauffeur et administrateur et corriger les défauts reproductibles. »

Ces fichiers définissent des agents de projet. Le compte GitHub et l’accès à Copilot se connectent dans VS Code. Leur présence dans le dossier ne lance aucune modification automatiquement.
